# Fichiers modifiables des outils

Aucun fichier modifiable séparé n’est fourni dans le manuscrit V3. Les modèles O01 à O18 restent consultables dans le guide. Ajouter ici uniquement des fichiers validés, puis renseigner leurs métadonnées et liens dans un catalogue maintenu séparément du manuscrit. Ne jamais inventer de téléchargement.
